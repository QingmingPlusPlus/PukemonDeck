# data — 外部数据目录

此目录用于存放**不纳入 git 版本控制、也不进入安装包**的开发数据文件。

## deck.db

卡牌只读数据库（SQLite，约 18 MB，2 万多张卡牌）。表结构见 [`docs/db/deck.sql`](../docs/db/deck.sql)。

### 开发环境使用方式

可把 `deck.db` 放到本目录，供开发时直接查询：

```
data/deck.db
```

`npm run dev` 会在没有用户导入副本时读取该文件。`electron-builder.yml` 已排除整个
`data/` 目录，因此即使此文件存在，打包时也不会将它复制进安装包。

### 运行时解析顺序

应用启动时按以下顺序查找卡牌库，并以只读方式打开：

1. 用户导入的副本：`app.getPath('userData')/data/deck.db`（持久保存，升级应用时保留）。
2. 可选的外部副本：开发期为本目录的 `deck.db`；打包后为 `<resources>/db/deck.db`，默认不存在。

正式安装包默认不含数据库，首次启动会显示导入页。用户可以通过文件选择框或拖放导入
`.db` / `.sqlite` 文件。导入通过校验后会复制到用户数据目录，重启后仍然可用。

进入应用后，可在“设置”页查看当前数据库的完整路径并重新导入。每次导入成功都会覆盖
之前的 `userData/data/deck.db`，原始所选文件不会被修改。

### 说明

- 文件缺失时不会导致构建或启动失败。
- 运行时始终以**只读**方式打开卡牌库，不做迁移。
- 用户库 `pukemondeck.db` 也保存在 `app.getPath('userData')/data/`，与卡牌库文件相互独立。
